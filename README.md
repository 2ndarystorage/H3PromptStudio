# H3 Prompt Studio

MiniMax H3の公式ガイドに沿った、ブラウザで使えるプロンプト作成ツールです。

## 機能

- T2VA / I2VA / FL2VA / L2VA / Ref2VAの5モード
- ショット、カット時刻、セリフ、環境音、BGMの編集と形式チェック
- 英語と日本語を別ウインドウ・タブで併記
- 12種類のサンプル、各9通り（計108通り）。再作成時は直前とは異なる案
- TXT / 日英TXT / 下書きJSONの保存、JSON読み込み、ブラウザ内保存

## 起動方法

Python 3を用意し、リポジトリのフォルダで実行します。

```sh
python -m http.server 8000 --directory dist --bind 127.0.0.1
```

http://localhost:8000 をブラウザで開いてください。追加パッケージやAPIキーは不要です。

## 使い方

1. モード、4〜15秒の長さ、比率を選択します。
2. サンプルを選ぶか、英語の映像・音を入力します。「別の案を作る ↻」で別バリエーションを出します。
3. 「英語＋日本語を別ウインドウで表示」で内容を確認します。サンプルには日本語訳が付いています。
4. 完成プロンプトをコピーして、ComfyUIなどのH3入力欄へ貼り付けます。長さ・比率・参照素材は生成先でも設定します。
5. 日本語から考える場合は「AI書き換え依頼を作成」の文章をAIに渡してください。

## 注意点

- 入力文章を組み立てるツールです。AI自動翻訳、素材解析、動画生成、公式H3-Context-IRの再現は行いません。
- 独自に編集した英文の訳は未入力と表示されます。翻訳依頼ボタンでAIへの依頼を作り、返された訳を入力できます。
- 下書きは端末のブラウザ内に保存されます。端末間の同期はありません。
- JSONはこのツールの下書き形式で、MiniMax APIのリクエスト形式ではありません。
- 別タブは開いた時点の内容です。修正後は開き直してください。
- ブラウザの実画面とH3による生成品質は未検証です。形式、サンプル変化、日本語対応、保存の処理はテスト済みです。
